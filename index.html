Paste Instructions
  1. Outlook: File → Options → Mail → Signatures → New → paste into the body area.
  2. Apple Mail: Mail → Settings → Signatures → uncheck "Always match my default message font" → paste.
  3. Gmail: Settings → See all settings → General → Signature → Create new → paste.
